# 特别飞机查询系统 Web MVP

一个面向航空爱好者的特别飞机发现工具。输入机场名称或代码，即可查看当天值得关注的特殊机型、彩绘机、稀有境外航司及临时包机。

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

## 当前范围

- 支持按机场名称、IATA、ICAO 代码查询。
- 内置 PVG、HKG、PEK 三个机场的演示数据。
- 支持特别涂装、特殊机型、稀有航司、临时包机分类筛选。
- 展示稀有度推荐值、到达状态、天气及跑道提示。
- 支持特别飞机详情侧栏及移动端适配。

当前数据均为产品演示用途，不代表真实航班动态。正式数据接入方案参见《系统设计文档.md》。
